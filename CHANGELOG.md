# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.0.0] - 2026-06-05

### Added

- BEM linter to `package.json` scripts.

### Changed

- **Breaking change:** bumped the minimum supported Node.js version to >=24.0.
- Updated README.md and LICENSE.
- Updated dependencies.

### Fixed

- Corruption of raster image files in optimization task.

## [2.0.0] - 2025-07-02

### Changed

- **Breaking change:** bumped the minimum supported Node.js version to >=20.0.
- Updated dependencies.

## [1.0.1] - 2024-05-30

### Changed

- Replaced `autoprefixer`, `cssnano` and `postcss-preset-env` with `postcss-lightningcss`.
- Updated dependencies.

## [1.0.0] - 2024-03-15

### Added

- Basic project configuration files.
- Initial file structure and template files for markup, styles, scripts and static.
